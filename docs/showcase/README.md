# Showcase — real projects, measured receipts

Case studies of real software built with coding agents served by
modelsteward. Not benchmarks: one machine, one config, one project at a
time — but every number is measured by the app itself (the token meter,
the trial harness, the quality probes), and every config is
reproducible from the writeup.

House rules for entries:

- **Aggregates only.** Meter totals, cache rates, measured cost, the
  applied config, quality scores. Never conversation transcripts or
  raw logs — the same line `--report` draws.
- **The artifact lives in its own repo**, linked; this directory holds
  the measured story.
- **Case study framing.** What happened, on what hardware, at what
  cost — with the caveats stated (cold prefill, single machine).
